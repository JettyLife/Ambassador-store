# Jetty Ambassador Store

Static ordering page for brand ambassadors. It's hosted on GitHub Pages, and nobody needs an account.

- `index.html`: the store, with the Summer 2027 Mens and Accessories catalog built in.
- `a/`: one encrypted file per ambassador. Each one opens only with that person's code from their personal link (`.../#CODE`). Names, emails and allowances are never stored here as readable text.
- `img/`: product photos. Name them `<STYLE>-1.jpg` (main) and `<STYLE>-2.jpg` (shown on hover), for example `0527BOTT-M1001APR-1.jpg`.

Do not commit the ambassador links list. It contains every code.
